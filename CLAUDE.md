# CLAUDE.md

## Default response style

Use the `caveman` skill (`.claude/skills/caveman/`) at its **full** intensity for
every reply in this repository, without waiting to be asked. Load it at the start
of a session.

The skill compresses prose only. It does not apply to anything that outlives the
chat: code, comments, commit messages, documentation, and issue or pull-request
text stay in normal English.

To turn it off for one session, say "normal mode".
